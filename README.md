โปรเจกต์หน้าเว็บไซต์ประชาสัมพันธ์สาขาวิชา (Coming Soon Page)
เว็บไซต์นี้จัดทำขึ้นเพื่อใช้เป็นหน้า Landing Page สำหรับประชาสัมพันธ์สาขาวิชา โดยเน้นการออกแบบที่ทันสมัย สะอาดตา และรองรับการแสดงผลบนอุปกรณ์เคลื่อนที่ เพื่อให้เข้าถึงกลุ่มนักเรียนและผู้ที่สนใจได้ง่าย

รายละเอียดการปรับแต่ง (Customization)
ในส่วนของงานดีไซน์ ได้มีการนำ CSS ของ Bootstrap 5 มาปรับปรุงใหม่เพื่อให้เข้ากับอัตลักษณ์ของสาขา ดังนี้:

โทนสีหลัก: ปรับเปลี่ยนเป็นสีเขียว (#2a5555) เพื่อสร้างความรู้สึกที่มั่นคงและเป็นมืออาชีพ

ระบบฟอนต์: * ใช้ฟอนต์ Tinos สำหรับหัวข้อ (Headings) เพื่อความสวยงามและอ่านง่าย

ใช้ฟอนต์ DM Sans สำหรับเนื้อหาทั่วไป เพื่อความทันสมัย

Layout: ใช้ระบบ Bootstrap Grid System ทำให้เนื้อหาจัดวางอย่างเป็นระเบียบทั้งในหน้าจอคอมพิวเตอร์และสมาร์ทโฟน

โครงสร้างโปรเจกต์
index.html: ไฟล์โครงสร้างหลักสำหรับใส่ข้อมูลแนะนำสาขา ช่องทางติดต่อ หรือแบบฟอร์มลงชื่อสนใจ

css/styles.css: ไฟล์สไตล์ที่รวบรวมการตั้งค่าสี (Variables) และการจัดการ Responsive (Media Queries)

assets/: (ถ้ามี) โฟลเดอร์สำหรับเก็บรูปภาพกิจกรรมของสาขา หรือโลโก้คณะ

วิธีการนำไปใช้งาน
แก้ไขข้อความประชาสัมพันธ์ในไฟล์ index.html ตรงส่วน <h1 class="display-1">

ปรับเปลี่ยนสีหลักได้ที่ส่วน :root ในไฟล์ CSS (ตัวแปร --bs-primary)

เปิดใช้งานผ่าน Web Browser เพื่อตรวจสอบความเรียบร้อยก่อนนำขึ้น Server
